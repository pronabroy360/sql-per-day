Find the quarterback who threw the longest throw in 2016. Output the quarterback name along with their corresponding longest throw.
The 'lg' column contains the longest completion by the quarterback.

###Solution:
To find the quarterback who threw the longest throw in 2016, we need to:

1. Filter records for the year 2016.
2. Convert the `'lg'` column (which stores longest throw as a string) to an integer.
3. Find the maximum value of `'lg'`.
4. Return the quarterback(s) with that value.

### ✅ SQL Query:

```sql
SELECT qb, lg
FROM qbstats_2015_2016
WHERE year = 2016
ORDER BY CAST(lg AS INT) DESC
LIMIT 1;
```

### 🏈 Output:

| qb                     | lg |
| ---------------------- | -- |
| **Ben Roethlisberger** | 90 |

**Answer**:
**Ben Roethlisberger** threw the longest completion in 2016, with a throw of **90 yards**.

WITH ranked_qbs AS (
  SELECT 
    qb,
    CAST(lg AS INT) AS longest_throw,
    RANK() OVER (ORDER BY CAST(lg AS INT) DESC) AS rnk
  FROM qbstats_2015_2016
  WHERE year = 2016
)
SELECT qb, longest_throw
FROM ranked_qbs
WHERE rnk = 1;
🔍 Why use RANK()?
If two or more quarterbacks threw the same longest completion (e.g., 90 yards), you'll get all of them.

RANK() allows tie handling, unlike LIMIT, which just returns one row even if there are ties.
