### Problem Statement
Find the 3-month rolling average of total revenue from purchases given a table with users, their purchase amount, and date purchased. Do not include returns which are represented by negative purchase values. Output the year-month (YYYY-MM) and 3-month rolling average of revenue, sorted from earliest month to latest month.

A 3-month rolling average is defined by calculating the average total revenue from all user purchases for the current month and previous two months. The first two months will not be a true 3-month rolling average since we are not given data from last year. Assume each month has at least one purchase.

CREATE TABLE amazon_purchases ( created_at DATETIME, purchase_amt BIGINT, user_id BIGINT);

### Solution:
```sql
WITH MonthlyRevenue AS (
    -- Step 1: Calculate total revenue per month, excluding returns
    SELECT 
        DATE_FORMAT(created_at, '%Y-%m') AS month,  -- Extract Year-Month
        SUM(CASE WHEN purchase_amt > 0 THEN purchase_amt ELSE 0 END) AS total_revenue
    FROM amazon_purchases
    GROUP BY month
),
RollingAvg AS (
    -- Step 2: Calculate 3-month rolling average using window function
    SELECT 
        month,
        -- Calculate the 3-month average
        AVG(total_revenue) OVER (
            ORDER BY month
            ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
        ) AS rolling_avg
    FROM MonthlyRevenue
)
-- Step 3: Output the year-month and rolling average, sorted from earliest to latest month
SELECT 
    month,
    ROUND(rolling_avg, 2) AS rolling_avg  -- Round the result to 2 decimal places
FROM RollingAvg
ORDER BY month;
```
